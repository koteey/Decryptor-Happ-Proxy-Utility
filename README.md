## 🛠 Подготовка окружения (Setup)
Инструкция по подготовке среды для перехвата и дешифровки данных.

### 1. Требования к устройству (Android)
* **Root-права:** Обязательны (Magisk или KernelSU). Без них `frida-server` не сможет внедриться в процесс.
* **Архитектура:** Убедитесь, что вы знаете архитектуру своего процессора. 
    * *Как узнать:* выполните команду `adb shell getprop ro.product.cpu.abi` (чаще всего это `arm64-v8a`).
* **HappProxy:** Приложение должно быть установлено и в нем должна быть вставлена ссылка на подписку.

### 2. Программное обеспечение (ПК)
* **Python:** Рекомендуется версия **3.10+**. [Скачать с python.org](https://www.python.org/).
* **ADB (Android Debug Bridge):** Должен быть добавлен в системный путь (PATH) или находиться в папке с проектом.

### 3. Установка Frida

1.  **Установка инструментов на ПК:**
    ```bash
    pip install frida-tools frida
    ```

2.  **Установка Frida-Server на телефон:**
    * Версия сервера должна **строго совпадать** с версией на ПК (проверить версию на ПК: `frida --version`).
    * Скачать здесь: [Frida Releases](https://github.com/frida/frida/releases) (ищите файл `frida-server-NN.N.N-android-arm64.xz`).
    * Распакуйте и загрузите на телефон:
    ```bash
    adb push frida-server /data/local/tmp/
    adb shell "chmod 755 /data/local/tmp/frida-server"
    ```

## 📂 Состав проекта
Для корректной работы в одной папке должны находиться следующие файлы:

| Файл | Описание |
| :--- | :--- |
| `adb.exe` | Инструмент связи с устройством. |
| `frida.bat` | Скрипт для быстрого запуска сервера на телефоне. |
| `happ_final.js` | JavaScript-хук для перехвата методов дешифровки. |
| `decryptor_happ.bat` | Основной управляющий скрипт. |

---

## 🚀 Запуск

1. Подключите телефон по USB (**отладка по USB** должна быть включена в настройках разработчика).
2. Запустите файл `decryptor_happ.bat`.
3. Откройте приложение **HappProxy** на телефоне.
4. Выполните **обновление подписки**.
5. В консоли появится вывод данных. Ищите самый большой ("жирный") отрывок текста — это и есть ваша подписка.
6. Смотри вывод.

## ⚠️ Важные примечания
* **Конфликт версий:** Если версии Frida на ПК и телефоне различаются, инъекция не удастся.
* **Стабильность:** Используйте качественный USB-кабель. Обрыв соединения ADB в момент внедрения скрипта приведет к ошибке.
