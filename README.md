🛠 HappProxy Decryptor Setup
Инструкция по подготовке окружения для перехвата и расшифровки конфигураций.

1. Требования к устройству (Android)
Root-права: Обязательны (Magisk или KernelSU). Без них frida-server не сможет внедриться в процесс приложения.

Архитектура: Узнать свою архитектуру можно командой adb shell getprop ro.product.cpu.abi (обычно это arm64-v8a).

Установленный HappProxy: Приложение должно быть установлено и настроено (вставлена ссылка на подписку).

2. Программное обеспечение (ПК)
Python: Рекомендуется версия 3.10 и выше. Скачать с python.org.

ADB (Android Debug Bridge): Должен быть в системном пути (PATH) или лежать в папке с проектом. Входит в состав Platform Tools.

3. Установка Frida
Открой терминал (CMD) на компьютере и выполни:

Установка инструментов на ПК:

Bash

pip install frida-tools
pip install frida
Frida-Server на телефон:

Скачай версию сервера, строго совпадающую с версией на ПК (проверить версию на ПК: frida --version).

Скачивать тут: Frida Releases (ищи frida-server-NN.N.N-android-arm64.xz).

Распакуй и закинь на телефон:

Bash

adb push frida-server /data/local/tmp/
adb shell "chmod 755 /data/local/tmp/frida-server"
4. Состав файлов проекта
Для работы скрипта в одной папке должны лежать:

adb.exe — для работы с телефоном через кабель.

frida.bat — батник для быстрого старта сервера на телефоне.

happ_final.js — JavaScript-хук для перехвата методов дешифровки.

decryptor_happ.bat — основной управляющий скрипт.

5. Запуск
Подключи телефон по USB (отладка должна быть включена).

Запусти  decryptor_happ.bat.

Открой приложение HappProxy на телефоне и обнови подписку.

Смотри вывод.

⚠️ Важные примечания
Версии: Если frida на ПК и frida-server на телефоне разных версий — работать не будет.

USB: Используй только оригинальный кабель, чтобы ADB соединение не обрывалось в момент инъекции.
